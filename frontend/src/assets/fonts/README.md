# Local font assets

These WOFF2 files are bundled with the frontend; the editor does not depend on
fonts installed in Windows or on a live font CDN. Latin and Latin Extended
subsets are included for Spanish text and diacritics.

| Family | Files | Source package / upstream | License |
|---|---|---|---|
| Montserrat Variable (weights 100–900; used at 800 and 900) | `montserrat-latin-variable.woff2`, `montserrat-latin-ext-variable.woff2` | `@fontsource-variable/montserrat` 5.3.0; Julieta Ulanovsky's Montserrat project | SIL Open Font License 1.1, see `OFL-Montserrat.txt` |
| Anton | `anton-latin*.woff2` | `@fontsource/anton` 5.3.0; Vernon Adams / Anton Project | SIL Open Font License 1.1, see `OFL-Anton.txt` |
| Bebas Neue | `bebas-neue-latin*.woff2` | `@fontsource/bebas-neue` 5.3.0; Dharma Type / Bebas Neue Project | SIL Open Font License 1.1, see `OFL-Bebas-Neue.txt` |

The notice and complete license for each family are kept beside these assets
and must remain included when redistributing the application. No font files
were modified.
